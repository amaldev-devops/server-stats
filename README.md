# Server Performance Stats (`server-stats.sh`)

A bash script to analyze core Linux server metrics.

## Requirements Met
- Total CPU usage
- Total memory usage (Free vs Used + percentage)
- Total disk usage (Free vs Used + percentage)
- Top 5 processes by CPU usage
- Top 5 processes by Memory usage
- **Stretch Goals:** OS version, uptime, load average, logged-in users, failed login attempts.

## How to Run

1. Make executable:
chmod +x server-stats.sh

2.Excecute

./server-stats.sh
